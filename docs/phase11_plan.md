# Phase 11 実装計画: タスク管理機能の統合（iOS/macOS リマインダー連携）

## 目的
ユーザーがタイマー開始時に「現在取り組むタスク名」を入力・選択できるようにし、完了時にそのタスク名をバックエンドへ保存することで詳細な行動記録を残せるようにします。
さらに、手動入力だけでなく**Apple純正の「リマインダー」アプリと連携し、既存のタスク一覧から選択できる仕組み**を構築します。

## 現状の確認
- バックエンド（FastAPI側）の `models.py` および `schemas.py` にはすでに `task_name` フィールドが存在し、APIもこれを受け取れる状態になっています。
- 現在は `TimerViewModel.swift` 内で「選択されたプリセット名」などをハードコーディングして送信しています。
- Apple純正のリマインダーアプリのデータを取得するには、標準フレームワークの `EventKit` (`EKEventStore`) を使用します。

## 提案する実装内容

### 1. リマインダーアクセス権限の追加
- プロジェクト設定（`Info.plist` 相当）に、リマインダーにアクセスする理由を記載したキー（`NSRemindersFullAccessUsageDescription` など）を追加し、初回起動時にユーザーに許可を求めるようにします。

### 2. ReminderManager の作成 (EventKit 連携)
- `EKEventStore` をラップした `ReminderManager` (ObservableObject) を新規作成します。
- **実装する機能**:
  1. リマインダーのアクセス許可要求
  2. 未完了のタスク（リマインダー）の一覧取得処理

### 3. TimerViewModel.swift の改修
- **状態の追加**: `@Published var currentTaskName: String = ""` を追加し、最終的に送信するタスク名を保持します。
- **データ送信処理の変更**: `saveRecord()` メソッドを修正し、`currentTaskName` に入力・選択されたテキストを送信するようにします。

### 4. TimerView.swift の改修 (UIの統合)
- タイマー画面上にタスクを指定するための複合UIを追加します。
- **UI仕様案**:
  - `TextField` を設置し、これまで通り**自由に手動入力**ができるようにする。
  - テキストフィールドの隣に「リマインダーから選択（リストアイコン等）」ボタン、あるいはドロップダウンメニュー（`Menu` や `Picker`）を配置する。
  - リマインダーからタスクを選択した場合は、そのタイトルが自動的にテキストフィールド (`currentTaskName`) にセットされる。もちろん、セットされた後に手動で微修正することも可能。
- 誤操作を防ぐため、**「タイマー実行中（isRunning == true）」は入力・選択部分を非表示または編集不可（Disabled）**にします。

### 5. 表示の確認 (Timeline / Stats)
- 現在のタイムライングラフやリストのUIで `task_name` が適切に表示されるか確認します。

## オープンクエスチョン（ご確認事項）
- **タイマー完了後のタスク名のクリアについて**: タイマー完了後、入力されたタスク名は一旦クリア（空文字）にした方が良いでしょうか？それとも連続して同じタスクを行う場合を考慮し、残したままにした方が良いでしょうか？
- **完了済みリマインダーの扱い**: 今回の実装では「純正リマインダーアプリ側のタスクを完了状態にする」ことまではせず、あくまで**「タスク名を取得・コピーするだけ」**という想定でよろしいでしょうか？（EventKitを使えばポモドーロ完了時にリマインダー側も「完了」にすることは技術的に可能です）

## 追加実装: 「完了して次へ (Complete & Next)」機能
予定より早くタスクが終わった場合に、タイマーをリセットせずに「これまでの経過時間」だけを現在のタスクとして保存し、残り時間を次のタスクに割り当てられるようにします。

### 1. TimerViewModel.swift の改修
- **状態の追加**: `@Published var lastSavedTimeRemaining: Int` を追加し、タイマー開始時（または前回保存時）の残り時間を保持します。
- **メソッドの追加**: `completeCurrentTaskAndContinue()` を実装します。
  - 経過時間 = `lastSavedTimeRemaining - timeRemaining`
  - 経過時間が60秒（1分）以上あれば、その時間分をバックエンドへ記録保存する。
  - `lastSavedTimeRemaining` を現在の `timeRemaining` に更新する。
  - `currentTaskName` をクリアし、次のタスク名を入力可能にする。
- **データ送信処理の変更**: `saveRecord()` が固定の `focusTime` ではなく、引数で受け取った経過時間（または `lastSavedTimeRemaining` から計算した時間）を送信するように修正します。

### 2. ContentView.swift (UI) の改修
- タイマー画面の操作パネルに **「完了して次へ」** ボタンを追加します。
- このボタンは「集中モード (`mode == .focus`)」の場合のみ有効・表示させ、休憩モードの時は隠します。
