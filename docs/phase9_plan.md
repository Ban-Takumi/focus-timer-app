# Phase 9: 1日のタイムライン表示（8:00起点）

## 目的
1日のうち「いつ、どれだけ集中したか」を視覚的に振り返ることができるようにします。
「今日の合計時間」だけでなく、時間帯ごとの集中度合いを可視化することで、自身の生産性のピークタイムの把握やモチベーションの維持に役立てます。

## 要件
1. **バックエンド**:
    - 指定した日（論理的な1日）のすべてのポモドーロセッション（開始時刻と持続時間）の生データを返すAPIを追加する。
    - 「1日」の定義を、標準の「0:00 〜 23:59」ではなく、「朝8:00 〜 翌朝7:59」とする。
2. **フロントエンド (SwiftUI)**:
    - 統計タブ内に新しいグラフ「今日のタイムライン」を追加する。
    - SwiftUI Charts を使用して、各セッションを棒グラフ（BarMark）として配置する。
    - 横軸（X軸）の表示範囲を「今日の8:00 〜 翌日の8:00」の24時間に固定する。
    - X軸のラベルを 8:00, 16:00, 24:00 (または0:00) のように8時間ごとに表示し、見やすくする。

## 実装ステップ
1. **バックエンドの機能追加**
   - `schemas.py` に、レコード単位の詳細を返す `RecordResponse` を定義する。
   - `main.py` に `/stats/timeline` エンドポイントを追加し、現在の時間に応じて「今日の8:00から翌朝7:59」または「昨日の8:00から今日の7:59」のレコード一覧を返す。
2. **SwiftUIのデータ連携**
   - APIクライアント (`NetworkService.swift`) にタイムライン取得関数を追加。
   - レコードを受け取る構造体を定義。
3. **グラフのUI構築**
   - 既存の週間グラフの下（または上）に `DailyTimelineChartView` を追加。
   - `.chartXScale(domain:)` モディファイアを使って、軸の開始を必ず8:00になるように調整する。
