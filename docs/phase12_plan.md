# Phase 12: デイリーゴール機能とデザインの洗練 - 実装計画書

## 1. 概要と目的
本フェーズでは、単なる時間計測アプリから「毎日の目標を達成したくなるアプリ」へと進化させるため、**1日の集中目標設定機能（デイリーゴール）**を導入します。また、それに伴い、Apple Watchのアクティビティリングのような**「円形プログレスバー（リングUI）」**を各画面（タイマー画面・ウィジェット）に適用し、デザイン全体の洗練とUXの向上を図ります。

## 2. 変更内容詳細

### 2.1. TimerViewModel.swift の拡張
- **目標時間と本日の実績管理:**
  - `@AppStorage`（または `UserDefaults(suiteName:)`）を用いて、ユーザーが設定した「1日の集中目標時間（分）」（デフォルト: 120分など）を保存・読み込みできるようにします。
  - バックエンドから取得した `weeklyStats` から「今日の合計集中時間（`todayTotalMinutes`）」を抽出し、Publishedプロパティとして保持します。これにより、タイマー完了時などにリアルタイムでリングが更新されます。

### 2.2. SettingsView.swift のアップデート
- **目標設定UIの追加:**
  - 「プリセット設定」の上に、新しいセクションとして「1日の集中目標設定」を追加します。
  - `Stepper` または `Slider` を用いて、目標時間（例: 30分〜600分）を柔軟に変更できるUIを提供します。

### 2.3. ContentView.swift (TimerView) のデザイン洗練
- **円形プログレスバー（アクティビティリング）の導入:**
  - 中央の残り時間（`Text(timeString)`）の周囲に、今日の目標達成率を示す美しい円形プログレスバー（`Circle`）を配置します。
  - タイマー作動時やタスク完了時に、リングのゲージが滑らかに伸びるアニメーション（`withAnimation`）を実装します。

### 2.4. FocusTimerWidget.swift のデザイン最適化
- **ウィジェットへのリングUI適用:**
  - `SmallWidgetView`（今日の集中時間）のレイアウトを改良し、ウィジェット上でも円形プログレスバーを描画します。
  - ユーザーが設定した目標時間（UserDefaultsを共有）と、APIから取得した今日の集中時間をもとに達成率を計算します。
  - これにより、Macのデスクトップ上でも直感的に「今日の進捗」がわかるようになります。

## 3. オープンな質問・確認事項
- **ウィジェットとアプリのデータ共有:**
  - アプリ側の設定（目標時間）をウィジェットに反映させるため、`UserDefaults(suiteName: "group.com.bantakumi.FocusTimer")` などのApp Group共有を使用します（ローカルビルドのMacアプリであれば通常問題なく動作します）。

## 4. テストと確認手順
1. アプリを起動し、「設定」タブで目標時間を変更できるか確認する。
2. タイマー画面（およびメインウィンドウのTimerView）で、数字の周りに円形プログレスバーが表示され、今日の達成率に応じてゲージが満たされているか確認する。
3. タイマーを「完了して次へ」で保存した際、リングのゲージが即座に伸びるか確認する。
4. デスクトップのウィジェット（Smallサイズ、またはExtra Largeサイズ）にリングUIが反映されているか確認する。
