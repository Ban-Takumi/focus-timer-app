## 🧭 プロジェクト設計図：自分専用ポモドーロ・トラッカー＆ウィジェット

### 📌 アプリ概要
* **目的:** 個人の作業時間を計測し、Macのホーム画面上で直感的に集中状態・統計を可視化する。
* **ターゲット:** 自分自身（ストア公開はせず、ローカル環境でサイドローディングして使用）。
* **コア体験:** 「タイマーで測る」→「データが裏側で保存される」→「ウィジェットで確認できる」のシームレスな連携。

### 🛠️ 採用技術スタック
1. **バックエンド（データ処理・API）: `Python` (FastAPI 推奨)**
    * **役割:** タイマーの記録を受け取り、データベースに保存。要求に応じて「今日の合計時間」などを計算して返す。
    * **選定理由:** 現在の研究で使い慣れている技術を活かし、最速で確実なデータ処理基盤を作るため。
2. **フロントエンド（アプリ画面）: `SwiftUI`**
    * **役割:** タイマーの開始・停止を行う操作画面。
    * **選定理由:** Apple製デバイスで最も美しく動作し、後述のウィジェット開発とコードを共有できるため。
3. **ウィジェット（ホーム画面表示）: `SwiftUI` (WidgetKit)**
    * **役割:** バックエンドからデータを取得し、Macのデスクトップに統計グラフや数値を表示する。

### 🚀 開発ロードマップ（3ステップ）

#### Phase 1: データの受け皿を作る（Pythonバックエンド開発）
まずは見慣れたPythonで、アプリの裏側の仕組みを構築します。
* [x] 開発環境の準備（FastAPIなどのインストール）
* [x] 簡単なデータベース（SQLiteなど）の設計（保存項目：日付、タスク名、集中時間など）
* [x] 記録を保存するAPI（POST）の作成
* [x] 統計データを返すAPI（GET）の作成（例：「今日の合計時間」を計算して返す）

#### Phase 2: タイマー画面を作る（SwiftUIアプリ開発）
新しい言語（Swift）に挑戦し、Mac（またはiPhone）で動くアプリ本体を作ります。
* [x] Xcodeのインストールとプロジェクト作成
* [x] SwiftUIを用いたタイマー画面（数字のカウントダウン、Start/Stopボタン）のUI作成
* [x] タイマー終了時に、Phase 1で作ったPython APIへデータを送信する通信処理の実装

#### Phase 3: ホーム画面を彩る（WidgetKit開発）
いよいよ最終目標であるウィジェット機能を実装します。
* [x] Xcodeのプロジェクトに「Widget Extension」を追加
* [x] Python APIから統計データ（今日の合計時間など）を取得する処理の実装
* [x] 取得したデータを表示する、ウィジェット専用のUI作成
* [x] 自分のMacにインストール（サイドローディング）して完成！

#### Phase 4: クラウド展開（インフラ構築）
自分専用のローカル環境から，どこからでもアクセス可能な本番環境へとシステムをアップグレードします．
* [x] クラウドデータベース（Supabase等のPostgreSQL）の準備と接続設定
* [x] FastAPIバックエンドのクラウドホスティング（Render等）へのデプロイ
* [x] SwiftUIアプリおよびウィジェット側のAPI通信先URLを本番環境へ切り替え
* [x] iPhoneなど複数デバイスからの同期確認

#### Phase 5: アプリ機能の拡充（ポモドーロサイクルの導入）

* [x] 休憩モード用のUI（色などの視覚的変化）の実装

現状の固定タイマー時間をユーザーが変更できるようにし、複数の時間設定プリセットを作成・保存できる機能を導入します。
* [ ] タイマー時間（集中時間・休憩時間）の自由変更機能の実装

タイマー開始時に「いまから何のタスクをやるか」を入力できるようにし、タスクごとの記録を残せるようにします。
* [x] 集中するタスク名の手動入力と、OS標準「リマインダー」アプリからのタスク取得機能
* [x] 「完了して次へ」ボタンによる、タイマーを止めないシームレスなタスク切り替えと記録保存
