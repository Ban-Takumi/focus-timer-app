# Phase 8: メニューバー（常駐）アプリ化

## 目的
FocusTimerをDockや通常のウィンドウ形式から、Macのメニューバーに常駐するアプリへと進化させます。これにより、作業中にウィンドウが邪魔にならず、いつでもワンクリックで素早くタイマーにアクセスできるようにします。

## 要件
1. **メニューバーへの常駐**
   - アプリを起動するとDockにアイコンを表示せず、直接メニューバーにアイコン（例：タイマーアイコン）を表示する。
2. **ポップオーバー表示**
   - メニューバーのアイコンをクリックすると、既存のタイマー画面（または専用のコンパクトな画面）がポップオーバーとして表示される。
3. **既存機能の維持**
   - 既存のタイマー機能（開始、停止、モード切替）や統計タブが引き続き機能すること。

## 変更予定のファイル

### 1. アプリ本体 (`FocusTimer/FocusTimer/`)
- **`FocusTimerApp.swift`**:
  - `WindowGroup` を `MenuBarExtra` に置き換え、メニューバーアプリとして動作するように変更。
  - アイコンはSF Symbols（例: `timer`）を使用。
  - ポップオーバーとして `ContentView` を表示。

### 2. プロジェクト設定 (`FocusTimer.xcodeproj / Info.plist`)
- **`Info.plist` (または Xcodeのターゲット設定)**:
  - `Application is agent (UIElement)` を `YES` に設定し、Dockアイコンとメニューバー（画面左上のファイルや編集メニューなど）を非表示にする。

## 留意点・検討事項
- 現在の `ContentView` はタブ切り替え（タイマー、設定、統計）を持っています。これをそのままポップオーバーに表示するか、それともメニューバー専用のよりスリムなUIを作るかは調整可能です。（本フェーズでは、まずは既存の `ContentView` をそのままメニューバーから開けるようにする方針です）
