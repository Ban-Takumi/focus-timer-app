# Phase 6: タイマーのカスタマイズとプリセット機能

## 目的
現在固定となっているタイマー時間（集中:25分 / 休憩:5分）をユーザーが自由に変更できる機能と、お気に入りの時間設定（集中時間と休憩時間の組み合わせ）を「プリセット」として保存・呼び出しできる機能を追加します。

## 要件
1. **タイマー時間の動的変更**
   - 現在の定数（25分、5分）を廃止し、設定画面からユーザーが任意の分数を指定できるようにする。
   - タイマーの動作ロジックを変更し、動的な時間に基づいてカウントダウンとサイクル切り替え（集中→休憩）を行えるようにする。
2. **プリセット管理機能**
   - 複数の時間設定（例：「ポモドーロ: 25分/5分」「ショート: 15分/5分」「ディープ: 50分/10分」）を保存・選択可能にする。
   - プリセットの新規追加、および削除ができるようにする。
3. **データ保存（永続化）**
   - 作成したプリセットや最後に設定した時間は、アプリを終了しても保持されるようにする（UserDefaultsやAppStorageなどを利用）。
4. **UIの実装**
   - メイン画面（タイマー画面）から設定を開くためのボタンを追加。
   - 設定画面（シートやナビゲーション遷移）を作成し、そこでプリセットの選択やカスタム時間の設定を行えるようにする。

## 決定事項（ご回答反映）
1. **設定ボタンの配置**: 画面右上に歯車アイコンを配置するなど、使いやすい形で適宜配置します。
2. **データの保存先**: 今後のiPhone同期を見据え、バックエンド（Python側）のデータベースへ保存し、API経由で取得・更新する設計とします。
3. **デフォルトプリセット**: 
   - 「学習: 50分 / 休憩: 10分」（ユーザー要望）
   - 「ポモドーロ: 25分 / 5分」（標準）
   - 「ショート: 15分 / 5分」（おすすめ追加）

## 変更予定のファイル

### 1. バックエンド (`backend/`)
将来の複数デバイス同期のため、バックエンド側でプリセットを管理します。
- **`backend/models.py`**:
  - `TimerPreset` モデル（`id`, `name`, `focus_minutes`, `break_minutes`）を追加。
- **`backend/schemas.py`**:
  - `PresetCreate`, `PresetResponse` スキーマを追加。
- **`backend/main.py`**:
  - `GET /presets/`: プリセット一覧を取得。
  - `POST /presets/`: 新しいプリセットを作成。
  - `DELETE /presets/{preset_id}`: プリセットを削除。
  - 初期化時にデフォルトプリセットが存在しない場合は自動作成する処理。

### 2. フロントエンド (`FocusTimer/FocusTimer/`)
- **`TimerViewModel.swift`**:
  - 定数だった `focusTime`, `breakTime` を変数に変更し、選択中のプリセットを保持。
  - バックエンドAPI (`/presets/`) と通信してプリセットを取得、追加、削除するネットワーク通信処理を追加。
- **`ContentView.swift`**:
  - 画面上部（ナビゲーションバーなど）に設定画面を開くためのボタン（歯車アイコン）を追加。
  - 選択中のプリセット名を小さく表示。
- **`SettingsView.swift` (新規作成)**:
  - サーバーから取得したプリセットの一覧表示・選択UI。
  - カスタム時間（分）を指定して新規プリセットを作成・サーバーへ送信する機能。
  - プリセットの削除機能。
